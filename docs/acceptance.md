- 오류·부분 결과와 정상 빈 결과를 구분한다. HTTP 상태, 파싱/구조 오류 및 마지막 성공 시각을 기록하며 인증 비밀은 출력하지 않는다.

### 휴양림별 카드 묶기 수정 (2026-09-09)

공식 휴양림 ID로 화면만 묶고 각 객실의 가격·정원·이름·예약 링크는 유지했다. 기록한 실제 56개 객실 응답을 새 묶기 함수에 넣어 **휴양림 카드 10개 / 객실 56개**, **검봉산 카드 1개 / 객실 선택지 8개**를 확인했다. 동일 이름의 다른 휴양림 구분, 원본 불변, 필터 후 가격 범위·개수, 오름/내림차순 보존 등 테스트 5개를 추가하여 총 25개가 통과했다. 타입 검사·린트·완성 빌드도 통과했다. 이번 수정은 원본 재조회나 브라우저 조작 없이 기록된 실응답과 자동 검사로 검증했다.

## 남아 있는 운영 제약

### Mac / Windows 지원 추가 (2026-09-09)

Windows용 `숲빈방 실행.cmd`, `숲빈방 인증 연결.cmd`를 추가했다. Node 버전 확인, npm.cmd 호출, 한글/공백이 있는 프로젝트 경로 및 인증 경로를 인자로 안전하게 다루도록 구성했다. 실행기 줄바꿈은 CRLF이며 Git 체크아웃에서도 유지한다. Windows 인증 입력은 Node가 직접 읽고 명령문으로 실행하지 않는다.

Mac은 기존 POSIX 0600 파일을 계속 사용한다. Windows는 POSIX 권한 검사만 생략하지 않고 DPAPI CurrentUser 암호화 형식만 저장/읽는다. 암호화 실패 시 평문 저장으로 대체하지 않는다. Windows의 자식 프로세스 종료는 프로그램이 실행한 특정 PID 트리만 대상으로 한다.

Mac에서 **테스트 42개 통과, Windows DPAPI 실검사 1개 건너뜀**, 린트·타입 검사·빌드 통과. 기존 본인 인증 읽기 호환성과 로컬 화면 HTTP 200을 확인했다. 실제 인증은 변경하지 않았다. Windows CI에서는 DPAPI 왕복 검사와 Windows 파일 저장/읽기를 실행하도록 설정했다. **현재 Windows 실제 실행, 브라우저 조작 및 실제 숲나들e 조회는 미검증이며 GitHub CI도 아직 실행하지 않았다.** 실행기 및 보호 방식 구현과 실기 검증을 구분한다.

근거: [Microsoft DPAPI CurrentUser](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.protecteddata), [Node Windows 배치 실행](https://nodejs.org/api/child_process.html#spawning-bat-and-cmd-files-on-windows), [Node 파일 권한](https://nodejs.org/api/fs.html#fschmodpath-mode-callback).

### 최종 배포 방식: 개인 컴퓨터 실행

사용자가 각자 내려받아 본인 컴퓨터에서 실행하는 방식으로 확정했다. 공용 웹사이트/운영자 계정 방안은 적용하지 않는다. README를 개인용으로 다시 정리하고, macOS 실행기·인증 연결 실행 파일 및 검색 화면의 첫 실행 안내를 추가했다. 인증 연결은 정상 로그인 메인 요청 1건의 HAR를 수동으로 연결하는 방식이며, 로그인 자동 연동은 아니다. 개발자 도구 감지 때문에 정상 인증 파일을 만들 수 없는 환경에서는 사용을 완료하지 못할 수 있다.

현재 로그인 자료의 파서 호환성을 읽기 전용으로 확인했으며 실제 인증 파일은 교체하지 않았다. 잘못된/다중 요청/비공식 출처 HAR 거부, 크기 제한, 인증 비밀 오류 출력 방지, 전용 파일 권한 및 원자적 교체 등 테스트 7개를 추가했다. 인증 경로 테스트 4개를 포함하여 총 36개가 통과했다. 새 UI의 브라우저 조작 검증과 다른 운영체제 검증은 수행하지 않았다. GitHub 업로드는 아직 하지 않았다.

- **로컬 MVP 검증 완료이며 공개 서비스 배포 완료가 아니다.** 이 Mac에서만 실행한다. 개인 인증 세션을 외부 서버에 업로드하지 않았다.
- 세션 만료 시 공식 사이트에 다시 로그인하고 승인된 로컬 세션을 갱신해야 한다. 개발자 도구 감지·접근 제한을 비활성화하거나 우회하지 않는다.
- 일반 Chrome에서는 공식 링크가 열렸다. Codex 내장 브라우저에서는 숲나들e 자체 오류 페이지로 이동하는 문제가 있으므로 Chrome 이용을 권장한다.
- 객실 직행 대신 각 휴양림의 공식 예약 입력 페이지로 연결한다. 공식 사이트에서 날짜·객실을 다시 선택해야 할 수 있다.
- 표시 가격은 원본의 전체 숙박기간 요금이다. 추가 인원 요금 대상은 별도 안내하며 입장·주차·할인 등 최종 결제금액은 공식 예약에서 확인해야 한다.
- 공개 운영 전에는 원본 조회의 허용 범위, 운영용 인증 및 세션 갱신 방식을 별도로 확정해야 한다.
