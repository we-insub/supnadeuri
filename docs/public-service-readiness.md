# 불특정 다수용 간편 이용 전환 검토

> 보류된 검토안: 이후 사용자가 외부 API 신청 없이 본인 로그인으로 사용하겠다고 명확히 지정했다. 따라서 아래 공식 연동 전환안은 실행하지 않으며, 현재 작업은 로컬 프로그램의 전용 Chrome 로그인 버튼이다.

확인일: 2026-09-09. 현재 구현 완료나 연동 승인 기록이 아닌, 일반 사용자용 전환의 선행 조건을 정리한 문서다. 기존 로컬 프로그램과 비공개 저장소는 변경하지 않았다.

## 사용자 경험 기준

사용자가 기술적 설정을 선택하지 않고 날짜·지역·인원 입력 → 실제 예약 가능한 객실 조회 → 공식 사이트 예약으로 이동하는 흐름을 목표로 한다. 설치 없는 웹 이용을 우선 검토한다. 이는 현재 로컬 실행 방식을 공개 배포했다는 뜻이 아니다.

- HAR 내보내기, 쿠키 복사, 키 입력, 실행 창 관리 등을 일반 이용자의 필수 절차로 삼지 않는다.
- 개인 로그인 세션 하나를 공용 서버에서 모든 사용자에게 공유하지 않는다.
- 로그인 필요 여부와 공식 인증 연동 방식은 승인된 명세로 확정한다. 로그인 없이 조회할 수 있다고 미리 약속하지 않는다.
- 예약과 결제는 기존 범위대로 공식 사이트에서 수행한다.

## 확인한 근거

1. 기존 로컬 구현은 파일로 저장된 본인 세션을 읽는다. Chrome에서 다시 로그인해도 파일이 자동 갱신되지 않는다. 파일 확인 성공과 원본 로그인 유효성은 서로 다르다. 최근 원본 403 및 AUTH_REQUIRED 기록이 있어 현재 실조회 성공을 보장할 수 없다.
2. [공공데이터포털의 국립자연휴양림 예약정보](https://www.data.go.kr/data/15134227/openapi.do)는 상세 설명에 2023-03-15~2024-02-28 예약 현황 자료라고 명시한다. 이 정보만으로 현재 빈방 재고 API라고 사용할 수 없다.
3. [디지털서비스 개방 포털](https://openservice.go.kr/main)은 국립자연휴양림 시설정보·예약현황 비교 및 예약 서비스를 민간 연동 사례로 안내한다. 따라서 공식 연계 경로는 존재한다. 다만 이 프로젝트의 이용 권한이나 조회 전용 API 제공 여부는 아직 확인하지 않았다.
4. [공식 서비스 개방 절차](https://openservice.go.kr/serviceProc)는 수요기관 선정, 이용 체결, 검증서비스 승인, 연계 테스트, 운영 API 인증키 발급 단계를 설명한다. 일반 숲나들e 로그인으로 해당 권한을 대신할 수 있다고 가정하지 않는다.

## 운영기관에 확인해야 할 사항

- 개인 운영 서비스도 참여 가능한지, 사업자/기관 자격이나 모집 시기 제한이 있는지.
- 예약 대행 없이 날짜·지역·인원에 따른 예약 가능 객실 조회만 연동할 수 있는지.
- 국립뿐 아니라 숲나들e 등록 공립·사립 자연휴양림까지 제공되는지. 국립 한정이면 원래 MVP 전체 범위는 충족되지 않는다.
- 동일 객실의 전체 숙박기간 가용성, 객실 정원, 숙박일별 요금 및 합계, 공식 예약 링크를 제공하는지.
- 조회 이용자에게 로그인이 필요한지, 필요하다면 공식 인증 연계와 만료/로그아웃 처리 규격은 무엇인지.
- 호출량, 캐시, 대외 표시와 운영 환경에 대한 조건 및 테스트 환경 제공 여부.

## 현재 중단 지점과 다음 단계

현재 공식 연동 권한·명세·국공사립 전체 제공 범위가 확보되지 않았다. 이 상태에서 자동 연결 버튼이나 공개 검색 화면만 추가해 완료로 표시하지 않는다. 원본 접근 제한을 우회하거나 타인의 인증을 수집하지 않는다.

다음 단계는 운영자 동의를 받아 공식 연계 가능 여부를 문의하고, 필요한 운영자 정보로 신청 절차를 확인하는 것이다. 아직 문의 발송·약관 동의·활용 신청·공개 배포는 수행하지 않았다. 승인된 명세를 확보한 뒤 기존 수집 계층을 공식 연동으로 교체하고 일반 사용자 흐름을 구현한다.

## 문의 초안 — 아직 발송하지 않음

자연휴양림의 예약 가능한 숙박시설을 날짜·지역·인원 조건으로 통합 조회하고, 예약 및 결제는 숲나들e 공식 페이지에서 진행하도록 연결하는 서비스를 검토하고 있습니다. 사용자의 로그인 쿠키를 수동으로 전달받는 방식이 아닌 공식 연계를 희망합니다.

예약 대행 없는 객실 가용성·정원·가격 조회 API 이용 가능 여부, 국립/공립/사립 제공 범위, 개인 또는 사업자 운영자의 참여 요건, 사용자 로그인 필요 여부 및 공식 인증 방식, 신청·검증 절차를 안내해 주시기 바랍니다. 현재 기관의 연동 승인을 받았다고 표시하거나 공용 서비스로 운영하지 않고 있습니다.
